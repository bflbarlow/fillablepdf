FillablePDF

Create fillable PDFs entirely in your browser.

Your files never leave your device. FillablePDF renders and rewrites PDFs using WebAssembly-free JavaScript running locally. There is no upload, no account, and no server.

How it works

  • Open an existing PDF or start from a blank page (Letter, Legal, or A4).
  • Pick a field tool — text, multiline, date, checkbox, radio, dropdown, or signature line.
  • Click on the page to place the field, then drag and resize it into position.
  • Configure the field in the Properties pane (name, default value, options, required, read-only, appearance).
  • Press Export PDF to download a real AcroForm PDF that can be filled in any PDF reader.

Project files

The Save button stores your whole project — the source PDF plus every field — as a single JSON file, so you can close the tab and pick up later. Open project restores it.

Keyboard shortcuts

  • V / T / C / R / D / S / M — select, text, checkbox, radio, dropdown, signature, multiline
  • Ctrl/Cmd + Z — undo; Ctrl/Cmd + Shift + Z — redo
  • Ctrl/Cmd + D — duplicate; Delete — remove field
  • Ctrl/Cmd + E — export PDF; Ctrl/Cmd + S — save project
  • Arrow keys — nudge field (hold Shift for 10pt steps)

Open source

Built with pdf-lib and PDF.js, both bundled locally. Part of the Free Open Tools suite.
